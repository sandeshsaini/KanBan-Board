# Kanban Board

Responsive Kanban board built with React + Vite.

## Run

```
npm install
npm run dev
```


## Features
- Add / edit / delete tasks (title, description, priority, due date)
- Move tasks between Todo, In Progress and Done
- Search by title, filter by priority and status
- LocalStorage persistence (tasks + theme)
- Dark / light theme, responsive layout
- Empty state, no-results state, form validation
